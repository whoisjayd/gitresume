# Deployment

The repository includes Dockerfiles for the backend/worker runtime and the frontend static nginx image, plus `docker-compose.yml` for the API, worker, frontend, and Redis services.

## Required services

- FastAPI API from `src/gitresume/main.py`.
- Taskiq worker using `gitresume.workers.broker:broker` and `gitresume.workers.generation_tasks`.
- Redis for state, events, token handoff, settings, and the Taskiq broker.
- Vite frontend served by nginx in the frontend container.

## Important environment variables

- `APP_MODE=self_hosted|hosted`
- `SESSION_SECRET_KEY`
- `FRONTEND_ORIGIN`
- `ALLOWED_HOSTS`
- `REDIS_URL`
- `AI_MODEL`
- Provider keys such as `GEMINI_API_KEY`, `OPENAI_API_KEY`, `ANTHROPIC_API_KEY`, `GROQ_API_KEY`, or `LITELLM_API_KEY`
- Optional `ALLOW_SAVED_BYOK` and `SETTINGS_ENCRYPTION_KEY`
- Optional GitHub OAuth values for hosted mode or private repository access

## Hosted production example

For a hosted deployment behind `https://gitresume.example.com`, use production settings that match the public origin and GitHub OAuth callback:

```env
ENVIRONMENT=production
APP_MODE=hosted
FRONTEND_ORIGIN=https://gitresume.example.com
CALLBACK_URL=https://gitresume.example.com/api/session/callback
ALLOWED_HOSTS=gitresume.example.com
SESSION_SECRET_KEY=<long random session secret>
SESSION_COOKIE_HTTPS_ONLY=true
REDIS_URL=redis://redis:6379/0
GITHUB_CLIENT_ID=<github oauth client id>
GITHUB_CLIENT_SECRET=<github oauth client secret>
```

Add `ALLOW_SAVED_BYOK=true` and `SETTINGS_ENCRYPTION_KEY=<fernet key or long passphrase>` when hosted users should manage encrypted saved provider keys or OAuth model-provider accounts.

## Verification

Run targeted deployment checks before publishing images:

```bash
uv run pytest tests/test_deployment_files.py -q
npm --prefix frontend run build
uv run ruff check src tests
docker compose config
```
